# Physics refinement plan

Baseline: physics PR #4 merge `a8282ac`.

1. **Self contact.** Keep direct parent/child collision disabled to avoid overlapping joint geometry, but allow all nonadjacent mechanism/chassis and sibling contacts. Test a folded nonadjacent link against the chassis and confirm it cannot pass through; rerun the imported robot under gravity and drive.
2. **Full CAD inertia.** Assemble the complete 3×3 tensor for each welded subtree, including rotated link tensors and all parallel-axis cross terms. Diagonalize the symmetric positive-definite tensor, rotate each rigid body, visual, collision shape, and joint frame to its principal axes, and use the three eigenvalues as Bullet inertia. Reject invalid tensors. Test a known cross-term tensor and an asymmetric welded subtree, then validate actual Bullet angular response and renderer geometry.
3. **Servo effort.** Define explicit per-actuator servo physics parameters in `sim.config` (stall torque/force, no-load speed, position and velocity gains, deadband), require them for servo-driven URDF joints, and apply a finite torque-speed/force-speed controller through the transmission. Honor direction and URDF effort limits. Test free movement, load stall, and invalid/missing settings.
4. **Calibration.** Provide a deployable FTC TeamCode CSV logging helper and a CLI to fit battery/motor and drivetrain response from real recordings with input validation and fit diagnostics. Load the resulting calibration into motor, battery, and drivetrain models. Validate format and recovery using synthetic fixtures; report clearly that a real robot fit remains pending until a team supplies a recording.
5. Run the full test suite and real renderer regressions, document evidence and remaining limits, commit, and ship through a PR.

## Execution and validation

- **Self contact:** `PhysicsIntegrationTest.nonAdjacentTipCollidesWithOwnChassis` retracts a tip toward its own chassis under Bullet and verifies contact stops the joint. Only directly joined bodies are ignored. The imported `MechanismPhysicsOpMode` ran with three dynamic bodies and two joints, ending at slide `0.024 m` and arm `0.420 rad` without instability.
- **Inertia:** `PrincipalInertiaTest` reconstructs a tensor with cross terms from principal moments and rejects an indefinite tensor. `PhysicsIntegrationTest.principalFrameProducesCrossAxisAngularResponse` applies a unit X torque impulse in native Bullet and observes the predicted negative Y angular velocity, confirming off-diagonal inertia affects actual dynamics. The imported renderer run confirms geometry and joints load in that frame.
- **Servo:** `ServoModelTest` checks the torque-speed envelope. `PhysicsIntegrationTest.specifiedServoStallsUnderContactAndReversesDirection` checks a finite-effort driven servo against an obstacle and command reversal. `SimConfigTest` checks config parsing and missing-field rejection.
- **Calibration:** `CalibrationPipelineTest` writes synthetic bench and drive CSVs from known parameters, runs the same CLI a team would use, reloads the output JSON, and recovers battery voltage/resistance, motor friction, translation/yaw response times, and acceleration caps within test tolerances. The imported `BasicMecanumOpMode` loaded a profile and completed forward/strafe movement; `IntakeDemoOpMode` captured a game piece (`gamePieceHeld=true`) with that profile loaded. [`CALIBRATION.md`](../../gui-runner/CALIBRATION.md) documents the deployable TeamCode logger and fitting workflow.
- **Regression:** `./gradlew test --offline --no-daemon` passed all modules, and `git diff --check` was clean. The sample `CalibrationRecorder` compiled as part of renderer TeamCode source compilation.

No physical FTC robot recording was available, so no real hardware parameters have been fitted or compared with measured robot motion. The on-robot logger has been compiled against this repository's SDK mock and still needs a run against a team's actual Control Hub/FTC SDK. Direct parent-child CAD contact remains exempt, wheel rollers are not modeled individually, and the chassis remains level.
